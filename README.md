# KaiOS app catalogue and OStore installer

This repository hosts the [app catalogue](https://garbagebuild.github.io/JScalated-Store/webapps.json)
and the [OStore installer page](https://garbagebuild.github.io/JScalated-Store/)
for KaiOS 3. OStore replaces the older JScalated Store listing. Existing apps
remain in the catalogue, and the old Store update manifest remains available
for devices that already installed it.

See [sources and updates](SOURCES-AND-UPDATES.md) for package layout and the
signature and device-testing limits.
